WSI Tiler QC

Local image patch extraction and exploratory image-quality screening

Source repository ↗

1. Image and parameters

PNG, JPEG, WebP, or TIFF if your browser decodes it. This is not an OpenSlide/SVS/NDPI/DICOM WSI reader. Maximum 32 megapixels.

Thresholds are adjustable heuristics, not validated pathology standards. Focus is measured by grayscale Laplacian variance (higher usually indicates more detail); blue/green saturated pixels are only a possible marking-artifact signal.

2. Exports

QuPath GeoJSON uses image pixel coordinates (level 0). CSV includes per-tile QC metrics. A ZIP contains accepted PNG patches, up to 200 patches and 100 MiB.

Run an analysis to enable exports.
